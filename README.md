# Spectrune Feedback

This private repository is the intake space for feedback from invited
Spectrune Beta testers. It is intentionally separate from the product source,
the development backlog, and raw product ideas.

## Flow

1. An invited Beta tester submits feedback as a GitHub Issue.
2. Every open Issue is added automatically to the private
   **Spectrune - Feedback** Project under **Feedback**.
3. Feedback remains here while it is reviewed and qualified.
4. The later operational pipeline will define how accepted feedback becomes
   development work in [`Spectrune/spectrune`](https://github.com/Spectrune/spectrune).

## Security boundary

Never include license keys, invitation codes, passwords, access tokens,
personal information, or other secrets in an Issue. This repository is private,
but it is not a secret-storage system. A tester's expiring Spectrune license is
separate from their GitHub repository access.

## Development boundary

This repository contains Beta feedback intake and discussion only. It does not
define or change Spectrune's `AGENTS.md`, agent skills, source code, Project
Pepper fields, branches, or Alpha/Beta/Stable release operations.

Use the **Beta feedback** Issue form for every submission.
